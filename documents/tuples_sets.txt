A tuple is an ordered, immutable collection written with parentheses.
Example: point = (3, 4)

A tuple can hold items of different types.
Example: mixed = (1, "hello", True)

You can access a tuple item by index, starting at 0.
Example: point[0] gives 3

Negative indexes count from the end.
Example: point[-1] gives 4

Slicing returns a new tuple from part of the original.
Example: point[0:2] gives (3, 4)

The len() function returns the number of items in a tuple.
Example: len((1, 2, 3)) gives 3

Tuples are immutable and cannot be changed after creation.
Example: point[0] = 10 raises an error

A tuple with one item needs a trailing comma.
Example: single = (5,)

Parentheses are optional when creating a tuple.
Example: t = 1, 2, 3 is a valid tuple

You can unpack a tuple into variables.
Example: x, y = (3, 4)

The in operator checks if a value exists in a tuple.
Example: 3 in (1, 2, 3) returns True

The .count() method counts how many times a value appears.
Example: (1, 2, 1).count(1) gives 2

The .index() method returns the position of a value.
Example: (10, 20, 30).index(20) gives 1

Tuples can be used as dictionary keys because they are immutable.
Example: d = {(0, 0): "origin"}

Tuples are faster and use less memory than lists.

A set is an unordered collection of unique items written with curly braces.
Example: s = {1, 2, 3}

A set automatically removes duplicates.
Example: set([1, 2, 2, 3]) gives {1, 2, 3}

The .add() method adds one item to a set.
Example: s.add(4)

The .remove() method removes an item and raises an error if missing.
Example: s.remove(2)

The .discard() method removes an item without raising an error.
Example: s.discard(99)

The in operator checks if a value exists in a set.
Example: 2 in {1, 2, 3} returns True

The union() method or | operator combines two sets.
Example: {1, 2} | {2, 3} gives {1, 2, 3}

The intersection() method or & operator returns common items.
Example: {1, 2} & {2, 3} gives {2}

The difference() method or - operator returns items in the first set but not the second.
Example: {1, 2} - {2, 3} gives {1}

The symmetric_difference() method or ^ operator returns items in either set but not both.
Example: {1, 2} ^ {2, 3} gives {1, 3}

Sets are mutable but can only hold immutable items.
Example: {1, 2, 3} is valid, but {[1, 2]} raises an error

A frozenset is an immutable version of a set.
Example: fs = frozenset([1, 2, 3])

You can convert a list to a set to remove duplicates.
Example: set([1, 1, 2, 2]) gives {1, 2}

The len() function returns the number of items in a set.
Example: len({1, 2, 3}) gives 3

Sets are unordered, so you cannot access items by index.
Example: {1, 2, 3}[0] raises an error
